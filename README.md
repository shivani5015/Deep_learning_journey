# NLP & Deep Learning Notes

A quick reference guide covering core Natural Language Processing (NLP) concepts and Deep Learning models.

---

##  Topics Covered

### 1. Deep Learning Basics
* **ANN (Artificial Neural Networks):** How neurons work, passing inputs forward, and updating weights back.
* **CNN (Convolutional Neural Networks):** Extracting key patterns from sequential data and images.

### 2. Natural Language Processing (NLP)
* **Text Representation:** Converting words into numbers (Bag of Words, TF-IDF, Word Embeddings).
* **POS Tagging:** Identifying parts of speech (Noun, Verb, Adjective) and handling tricky words.
* **NER (Named Entity Recognition):** Finding real-world names, places, and organizations in text.
* **Topic Modeling:** Automatically finding themes in huge text datasets using LDA and checking topic quality with Coherence Scores.
